# 🛒 Django Mini Store

## 📌 Overview
Django Mini Store is a simple eCommerce web application built using Django.  
It allows users to browse products, add items to a cart, and place orders.  
The system also includes an admin panel for managing products and users.

---

## 👤 Target Users
- Online shoppers  
- Beginners learning Django  
- Small-scale eCommerce systems
